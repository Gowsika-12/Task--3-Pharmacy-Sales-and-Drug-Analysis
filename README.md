Pharmacy Sales & Drug Analysis

📊 Project Overview
This project analyzes pharmacy sales data to identify medicine usage trends, revenue patterns, monthly sales performance, and differences between branded and generic medicines.

🎯 Objectives
Identify top-selling medicines based on quantity sold
Analyze top medicines by revenue
Track monthly sales trends and growth
Compare branded vs. generic medicines
Analyze revenue by medicine category
Create an interactive dashboard to present key findings

🛠️ Tools Used
Microsoft Excel
PivotTables
Excel Charts
Excel Formulas
GitHub

📋 Dataset
The dataset contains pharmacy sales information including:
Sale ID
Date
Medicine
Category
Medicine Type (Branded/Generic)
Quantity Sold
Unit Price
Total Sales
Month

📈 Analysis & Visualizations
The dashboard includes:
Top 10 Medicines by Quantity Sold
Top 10 Medicines by Revenue
Monthly Sales Trend
Branded vs. Generic Revenue Comparison
Revenue by Medicine Category
Key Performance Indicators (KPIs

💡 Key Insights
The analysis helps identify:
Medicines with the highest sales volume
Medicines generating the highest revenue
Monthly changes in pharmacy sales
Revenue contribution from branded and generic medicines
Categories contributing most to overall revenue

📌 Conclusion 
This project demonstrates the use of Excel for healthcare and pharmacy data analysis, including data cleaning, PivotTables, data visualization, and dashboard creation.
